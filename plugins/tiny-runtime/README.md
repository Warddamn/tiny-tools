# tiny-runtime plugin

Resumable API batches, repeated-failure traces and tool-progress cache hints, by **AVRG3**.

Install with `/plugin marketplace add Warddamn/tiny-tools`, then `/plugin install tiny-runtime@tiny-tools`. Requires Node.js 20+. Provides the server and usage guidance; automatic guarding and live cache application require host integration.
